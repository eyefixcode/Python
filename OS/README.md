## 🍎 MacOS

Shell scripts intended for macOS environments to simplify development setup and common tasks.

- 🧪 **JupyterLab.sh** — launches JupyterLab from the terminal  
- 🔓 **MakeExec.sh** — updates file permissions to make scripts executable  
- 📦 **py_lib_install.sh** — installs common Python libraries via the command line  

---

## 🪟 Windows (WinOS)

Batch scripts designed for Windows command-line environments.

- 🎨 **Change_CMD_Color.bat** — customizes the Command Prompt color scheme  
- 📓 **Jupyter.bat** — launches Jupyter from the command line  
- 📦 **py_lib_install.bat** — installs common Python libraries on Windows  

---

## 🚀 How to Use

1. Navigate to the folder matching your operating system  
2. Open the script to review commands and assumptions  
3. Execute from the terminal or command prompt as appropriate  

These scripts are intended as **convenience tools** and can be modified to suit individual workflows.
