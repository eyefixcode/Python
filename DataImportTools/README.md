# 📥 DataImportTools

A collection of Python scripts focused on importing, parsing, and preparing data from common file formats for downstream analysis.

This folder serves as a **utility layer** for data ingestion.  
Each script is designed to handle a specific file type and can be used independently or integrated into larger workflows.

## 📊 Flat & Structured Data

Scripts in this group handle structured or semi-structured data formats commonly used in analytics pipelines.

- 📊 **Import_CSV_Data.py** — imports tabular data from CSV files  
- 🗂️ **Import_JSON_Data.py** — parses JSON data into usable Python structures  
- 🧾 **Import_XML_Data.py** — extracts data from XML files

---

## 📝 Document-Based Data

Scripts focused on extracting data from document formats that require additional parsing.

- 📘 **Import_DOCX_Data.py** — extracts text and content from Word documents  
- 📕 **Import_PDF_Data.py** — parses and extracts data from PDF files

---

## 🚀 How to Use

1. Select a script based on the file type you want to import  
2. Open the script to review any assumptions or required libraries  
3. Run locally with Python and adapt the output for your workflow  

These tools are commonly used as the **first step** in data analysis or visualization pipelines.

---

## 🎯 Purpose of This Folder

The `DataImportTools` directory demonstrates:

- flexible data ingestion workflows 📥  
- handling of multiple real-world data formats 🧩  
- preparation of raw data for analysis and visualization 🔄  

Each script is intentionally small, focused, and reusable.
