## 🎯 Supervised Learning

Supervised learning models trained on labeled data to perform prediction or classification tasks.  
Examples in this section focus on healthcare- and analytics-oriented use cases.

- 📈 **LinearReg_ex.py** — linear regression fundamentals and continuous outcome prediction  
- 🧬 **Disease_LogisticRegression.py** — logistic regression for disease classification  
- 🌳 **Healthcare_DecisionTree.py** — decision tree modeling for healthcare-related decisions  
- 🧠 **Healthcare_KNN.py** — k-nearest neighbors classification using distance-based learning  
- 🧮 **Healthcare_SVM.py** — support vector machine classification with margin optimization  

---

## 🔍 Unsupervised Learning

Unsupervised learning models used to uncover structure, patterns, and relationships in unlabeled data.

- 📊 **K-MeansClustering_Example.py** — general k-means clustering example  
- 🏥 **K-MeansClustering_HealthExample.py** — k-means clustering applied to healthcare data  
- 🚨 **AnomalyDetection_ex.py** — anomaly detection for identifying outliers and unusual patterns  
- 📉 **PCA_ex.py** — principal component analysis for dimensionality reduction  
- 🧬 **PCA_HealthEx.py** — PCA applied to healthcare-related datasets  
- 🔻 **DimensionalityReduction_ex.py** — general dimensionality reduction techniques  
- 🏥 **DR_Healthcare.py** — dimensionality reduction applied to healthcare data
