## 🏃‍♂️ Exercise

Pose-based workout counters that use real-time video input (typically a webcam) to detect movement and count repetitions.

- 💪 **pushup_Counter.py** — counts push-ups using body landmark motion
- 🧍 **situp_Counter.py** — counts sit-ups (often best from a side-facing angle)
- 🏋️ **squat_Counter.py** — counts squats using lower-body movement patterns

## 🧰 Automation & Utilities
